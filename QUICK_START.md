# Быстрый запуск

**Самая частая задача:** напишите «Я сделал сайт / видео / программу / приложение …». AI должен создать готовую страницу проекта для портфолио, а не сначала собирать бриф. Смотрите `prompts/PORTFOLIO_ONE_MESSAGE.md` и `skills/architektonica-portfolio-case-writer/SKILL.md`.

## В ChatGPT

1. Создайте проект Architektonica (если он уже есть — используйте его).
2. Вставьте `PROJECT_SYSTEM_PROMPT.md` в инструкции проекта.
3. Прикрепите файлы из `references/project/`. Для задач с психологией выбора прикрепите исследовательский реестр; для поклеточного заполнения сайта — исходный Excel Engine.
4. Отправьте один из запросов ниже. Не обязательно устанавливать все девять навыков: инструкции и файлы работают как справочник даже без нативной поддержки Agent Skills.

## В Perplexity Spaces

1. Создайте Space Architektonica.
2. Поместите в инструкции содержимое `prompts/PERPLEXITY_SPACE.md`.
3. Добавьте документы из `references/project/` и исследовательский реестр. Если среда ограничивает число файлов, загрузите Fact Bank, Services, Case Studies, Brand Core и Creative Platform; остальные подключайте по задаче.
4. Не смешивайте поисковые сведения о рынке с доказательствами собственных результатов студии.

## В Claude Code / иной Agent Skills среде

1. Скопируйте директории `skills/`, `methods/`, `references/` в рабочий проект с сохранением относительных путей.
2. Если хост ожидает другую папку навыков — переместите папки `architektonica-*/` в `.claude/skills/` или аналогичную и обновите в них ссылки на `methods`/`references`.
3. Добавьте `PROJECT_SYSTEM_PROMPT.md` в проектную инструкцию агента.
4. Убедитесь, что агент умеет читать `.xlsx`; если нет, предоставьте выводы из `methods/research-evidence-map.md` и экспорт нужных листов текстом.

## Примеры команд

**Новая главная:**
> Придумай три самостоятельные концепции главной Architektonica: одна через необычную деталь работы, одна через путь клиента, одна через стратегическое противоречие. Сам выбери лучшую и напиши всю главную. Возьми только реальные проекты. Готовый текст важнее объяснений.

**Страница услуги:**
> Напиши страницу «Брендинг». Покажи, какие решения меняются благодаря айдентике, а не перечисляй логотип, палитру и носители. Если нет публичного кейса этой услуги, не выдумывай его — найди иной способ убедительно объяснить ценность.

**AI-направление:**
> Напиши AI-страницу для R&D-директора: точный терминологический язык, сильная история про решение химика, ясное различение архитектуры, интерфейсного прототипа и предложенной проверки. Объясни, почему это интересно бизнесу, но не объявляй запланированные функции внедрёнными.

**Кейс:**
> Преврати досье «Арктическая Венеция» в живой кейс. Текст должен быть похож на историю, которую хочется дочитать; роль и итог работы назови предметно, без рекламного жаргона. Нужны заголовок, лид, блоки, финал.

**Критическая редактура:**
> Представь, что текст уже написан. Найди пять мест, где он кажется неоригинальным или неубедительным, затем сразу представь исправленную версию. Не вычищай хорошие образы только за то, что это образы.

**Для Excel Engine:**
> Заполни колонку E в копии исходного шаблона Engine по всем полям главной страницы. Не изменяй идентификаторы и остальные колонки. Пропускай фейковые отзывы, цифры и награды; предложи честную замену блоков и сохрани её отдельно.
