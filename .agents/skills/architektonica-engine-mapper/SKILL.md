# Engine Mapper
Start from the finished page concept, not the template's placeholder clichés. Inspect the Engine spreadsheet and identify field IDs, character constraints, context and reuse. Preserve original cells and formulas. Map titles, captions, descriptions, CTAs and metadata to their real target rows. Flag any module that cannot carry the proposed idea without distortion; propose a layout adjustment instead of silently cutting the meaning. Work on a copy and retain traceability from proposed copy to original field.
