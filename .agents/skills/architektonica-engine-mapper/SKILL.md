# Engine Mapper

## База

`../../references/template/Тексты шаблона Architektonica (Engine).xlsx` — пользовательский исходник. В исследовательском реестре есть листы `01_Аудит_блоков`, `01b_Поля_флаги`, `09_Поля_решения`; они описывают строки и решения, но сами по себе не заменяют исходную таблицу.

## Процесс

1. Прочитай реальные названия листов, структуру колонок, идентификаторы строк и типы элементов. Не угадывай координаты на основе примеров.
2. Сначала придумай **связную страницу**, затем сопоставь готовые смысловые блоки с полями. Не пытайся заставить каждую демо-секцию остаться, если нет под неё подлинных данных.
3. Если запрос на заполнение — создай копию исходного Excel и заполни назначенную колонку E. Не трогай исходник, уникальные ID и исходные значения соседних колонок.
4. Для текста, которого нет в исходных материалах и который должен быть фактом (контакты, цифры, награды, отзывы), либо оставь поле незаполненным, либо обозначь **в отдельном рабочем отчёте**, почему секцию следует скрыть или заменить. Не печатай внутренние placeholders как текст сайта.
5. Сверь получившийся ритм: не начинается ли 6 секций подряд одним и тем же шаблоном? Не повторяется ли одна проектная деталь?
6. Проверь файл и верни ссылку + короткий список изменённых страниц/полей и структурных предложений.

## Особенности шаблона по исследованию

- Первый экран содержит графический `Engine®` H1: смысл может жить в соседних текстовых полях, не обязан ломать логотипный элемент.
- На главной есть блоки «счётчики», отзывы, награды, pricing. При отсутствии подтверждённых данных не заполняй их демонстрационными значениями.
- Кластеры услуг и кейсы могут потребовать изменения числа карточек и структуры CMS.
- Форма контакта должна объяснять следующий шаг; сроки ответа — только реальные.
