# Critical Editor
Review against source-backed facts and the page's intended reader action. Find generic interchangeable sentences, dramatic claims without proof, invented results, repetitions, implausible technical descriptions and metaphors that obscure meaning. Preserve strong original language even if it uses a familiar rhetorical device. For each real issue, supply a better replacement and explain briefly why it works. Distinguish editorial preference from error. Finish with a ready-to-use corrected version rather than a list of prohibitions.
