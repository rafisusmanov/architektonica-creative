# Search Visibility

## Поиск не должен диктовать смысл

Работай **после** того, как есть сильная авторская версия страницы. Не превращай главную в каталог поисковых фраз. Оптимизация должна делать содержание обнаруживаемым, извлекаемым и понятным — не перезаписывать его.

## Что делать

1. **Намерение запроса.** Определи, какие задачи ищут: разработка сайта клиники, AI для фармацевтического R&D, интерактивный спецпроект, GEO для компании, бренд-айдентика и т.п. Не придумывай частотность или позиции без инструментов.
2. **Структура.** Title, description, H1 и логические H2. Содержательные ответы на ключевые вопросы. Нет обязанности использовать все ключи в первых 100 символах.
3. **Страницы услуг.** Каждая практика должна иметь свою логику, примеры, специфический язык и вход по ситуации — особенно при широком перечне направлений.
4. **Entity consistency.** Названия Architektonica и Synapto, имена основателей, проектные клиенты, связи работ и услуг — одинаковы во всём корпусе. Schema.org только по проверяемым сведениям.
5. **AI search.** Пиши точные определения, компактные цитируемые абзацы, вопросы и ответы там, где уместно. Хорошо сформулированный факт полезнее «секретов оптимизации для нейросетей».
6. **Внутренние связи.** Кейсы ссылаются на подходящие услуги; услуги — на конкретные работы; About — на практики; не замыкай все пути на главную.
7. **Проверка.** Если есть реальная аналитика/поисковая консоль — используй её; если нет, обозначь гипотезу и способ проверки.

## Запрещать? Нет. Разделять

`Креативный H1` может быть необычным, если подзаголовок объясняет деятельность. `SEO title` может быть прямым и предметным. Это две разные поверхности с разными задачами.

**Пример:**

- H1 кейса: «У нефтяной платформы появились достопримечательности».
- Meta title: «Арктическая Венеция — интерактивный спецпроект для Газпром нефти | Architektonica».

## GEO без гарантий

Никакой skill не обеспечивает автоматически цитирования ChatGPT/Google/Perplexity. Не повторяй непроверенные показатели эффективности приёмов. Смотри методики: `../../references/github-sources.md`; факты в проектных файлах.

## Результат

Для существующей страницы: улучшенная версия + SEO title, meta description, H1/H2, адресный slug, идеи внутренних ссылок; для стратегии — компактная карта страниц и поисковых намерений с пометкой, что объёмы и конкуренция требуют актуальных данных.
