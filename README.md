# Architektonica Creative Engine

Creative skills for writing the Architektonica website. Nine working agent skills are under `.agents/skills/`; start with `PROJECT_SYSTEM_PROMPT.md` and `AGENTS.md`. The original v1 package contains 39 files; supporting project references, research spreadsheets and examples are not yet uploaded to this GitHub repository.

## Workflow

Read source facts and research; find a distinctive angle; design a page narrative; write finished Russian copy; revise for authenticity, credibility and search visibility. Do not ask the user to invent headlines or slogans.
