# Как применять Creative Engine из GitHub

Приватный репозиторий: `rafisusmanov/architektonica-creative`.

## Порядок при работе с проектом

1. Читайте `AGENTS.md` и `skills/architektonica-portfolio-case-writer/SKILL.md`, если пользователь описал сайт, видео, программу, приложение или другой выполненный проект.
2. Если проект уже есть в документах — при необходимости найдите его в Fact Bank и Case Studies. Если проект новый — его источником выступает сообщение пользователя.
3. Применяйте методы и вспомогательные навыки по ситуации, не заставляйте пользователя писать за вас.
4. Верните готовую публикационную страницу и небольшой пакет для размещения на сайте.

## Среды

- **ChatGPT + подключённый GitHub:** можно обращаться к файлам репозитория, но это не означает автоматической установки этих SKILL.md как системных навыков. Используйте проектные инструкции или команды из `prompts/`.
- **Codex / Agent Skills:** для автоматического обнаружения навыков используются копии из `.agents/skills/`. Их синхронизация с `skills/` проверяется скриптом `scripts/verify_package.py`.

GitHub — актуальное хранилище файлов; подключённые среды могут кэшировать содержимое, поэтому при изменении важных методов обновляйте рабочий контекст.
