# Reader Insight

## Начинай с ситуации, а не с демографии

Для каждой страницы определи: **что случилось**, почему человек теперь ищет решение, что мешает ему выбрать, в каких словах он описывает задачу, какое действие сможет сделать после чтения. Портрет — рабочая гипотеза, если не взят из интервью.

**Три масштаба читателя:**

- **Руководитель / покупатель услуги:** думает о риске, сроке, стоимости владения, координации людей и последствиях ошибки. Заголовок — на языке рабочей задачи; детали доказательств — ниже.
- **Специалист:** проверяет терминологию, происхождение данных, воспроизводимость, применимость в текущем процессе. Не «объясняй» ценой технической неточности.
- **Бренд / продюсер / маркетинг:** ищет характер идеи, возможность показать невозможное, реакцию людей, качество исполнения, будущую жизнь проекта.

Для широких направлений — бухгалтерия, аналитика, продажи, SEO/GEO, брендинг — не подменяй самостоятельную компетенцию образами из фармы или девелопмента. Каждая практика получает **собственную конкретную ситуацию**. Не объявляй её зафиксированным клиентским запросом.

## Метод работы

1. Выпиши внутренне `работа человека / препятствие / опасение / проверяемый знак / следующий шаг`.
2. Проверь, какие части подтверждены реальными отзывами/интервью, а какие — гипотезы.
3. Если аудитория смешанная, организуй текст слоями: заголовок понятен руководителю; абзац с механикой убеждает специалиста; примеры показывают реальность.
4. Подбирай язык к теме. Для сложной AI-системы «интерфейс к моделям», «текущие лабораторные процессы», «исторические данные» — уместно; для клиники «эффективная инновационная экосистема» — нет.
5. Не пытайся пугать проблемами. Узнавание задачи не равняется агрессивному давлению на боль.

## Пример — один сервис, две роли

**Для R&D-директора:** «Пока прогноз нельзя проверить на истории вашей лаборатории, он не становится основанием менять исследовательский процесс» (позиционное рассуждение о предлагаемой проверке, не отчёт о состоявшемся пилоте).

**Для химика:** «В прототипе рабочей среды можно посмотреть позу лиганда в белковом кармане и зафиксировать причину отклонения кандидата» (демонстрация интерфейса, не вычислительная продуктивность внедрённой платформы).

## На выходе

Для внутреннего брифа — 5 строк об одной аудитории; для задания «напиши текст» — сразу выдавай готовый текст, не заставляя пользователя отвечать на анкету. Основания: M01, M03, M06 из исследования; см. `../../methods/research-evidence-map.md`.
