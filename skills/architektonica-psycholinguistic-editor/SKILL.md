# Psycholinguistic Editor

## Не «добавить триггеры», а улучшить восприятие

Работай с `../../references/research/Architektonica_реестры_исследования.xlsx`: листы `05_Выводы`, `06_Механизмы`, `07_Гипотезы`, `09_Поля_решения`. Для быстрого доступа — `../../methods/research-evidence-map.md`. Источник особенно полезен тем, что **явно отмечает пределы переноса исследований на сложные B2B-услуги**.

## Применение по цели блока

| Цель | Механизм | Проверка в тексте |
|---|---|---|
| Читатель узнаёт свою задачу | M01 | Ситуация конкретная, не придумана как клиентская история? |
| Быстро ориентируется, но замечает особенность | M02 | Привычна навигация, свеж сам материал? |
| Понимает без утраты технической точности | M03 | Уровень терминов соответствует роли? |
| Представляет стоимость усилий и порядок работы | M04 | Показаны артефакты/этапы вместо заявления «работаем комплексно»? |
| Мысленно проживает кейс | M05 | Есть ситуация, ограничение, действие; скептику даны аргументы? |
| Верит самостоятельной компетенции каждой практики | M06 | Нет маскировки 11 направлений одним поверхностным слоганом? |
| Находит направление через свою задачу | M07 | Есть вход по ситуации и полный доступ к каталогу? |
| Оценивает риск рационально | M08/M10 | Реальные границы, этапы, доказательства, без ложных гарантий? |
| Переходит к контакту без сопротивления | M09 | Понятен малый следующий шаг, нет навязанной срочности? |
| Заинтересован образом будущего результата | M11/M14 | Образ служит информации, не подменяет её? |

## Как редактировать

1. Определи фактическую функцию блока (захват внимания, пояснение, доказательство, навигация, действие).
2. Выбери **один или два** реально подходящих механизма — это не ограничение числа приёмов в тексте, а защита от механического нагромождения методик.
3. Найди фактуру или реальную пользовательскую ситуацию, через которую механизм можно выразить литературно.
4. Проверь в реестре, что подтверждено, где B2C перенос только косвенный, а где есть противоречия/репликации.
5. Отредактируй текст; не надо рассказывать читателю сайта о психологических механизмах.
6. Предложи проверку там, где она реально доступна: 5-секундный тест понимания, tree test, интервью, CTR, отправка формы. Не выдавай гипотезу за эффект.

## Принципиальные границы реестра

- F07: скептические/аналитические читатели нуждаются в сильных аргументах; история не замена фактуре.
- F04: слабое основание для мифа «конкретные слова автоматически кажутся правдивыми».
- F20: скрытые влияния, нейромаркетинговые обещания и универсальные nudges не служат доказательством продаж.
- F21: метафора может влиять на отношение, но не доказано, что сама повышает оценку компетентности.
- F10: не существует универсального правила «меньше выбора всегда лучше»; важны сложность задачи и предпочтения.
- F09: B2B-эмоции описаны в контексте в том числе корреляционных, а не причинных данных.

## Результат

При запросе на текст — переписанный текст. При запросе на научную оценку — краткая таблица `приём → F/M/ST-ID → применимость → что не доказано → как протестировать`. Не требуй от пользователя вручную подбирать исследования.
